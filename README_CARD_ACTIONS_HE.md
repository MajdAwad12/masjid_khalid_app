# תיקון כפתורי עריכה ומחיקה — אפליקציית המסגד

## השינויים
- **الإعلانات / الأخبار**: כפתורי `تعديل` ו־`حذف` בתחתית הכרטיסייה, באותו סגנון כמו שיעורי הבית.
- **الدورات**: לצד `تعديل` ו־`إدارة المسجلين`, נוסף `حذف` משמאל בסידור RTL.
- **الأنشطة والرحلات**: אותו סידור כפתורים.
- מחיקה מתבצעת רק אחרי אישור מפורש, ורק מנהל שאומת בצד השרת יכול לבצע אותה.
- מחיקת קורס מוחקת את מסמך הקורס; טריגר Firestore מחק לאחר מכן את כל ההרשמות הקשורות.
- מחיקת פעילות מוחקת את מסמך הפעילות; טריגר Firestore מוחק לאחר מכן את ההרשמות ואת קובץ התמונה המקושר.
- אין שינוי בעיצוב הכרטיסיות, בדרכי הרשמה, או במצב יום/לילה.

**אזהרה:** מחיקה לצמיתות מסירה גם את פרטי הנרשמים. יש לבצע גיבוי Firebase לפני בדיקה על נתוני אמת. ניקוי ההרשמות והתמונה הוא אסינכרוני: ייתכן עיכוב קצר אחרי שהכרטיסייה נעלמת.

## התקנה
1. בצעו commit או גיבוי לפרויקט הנוכחי.
2. הורידו את ZIP התיקון והניחו אותו בשורש `C:\development\projects\masjid_khalid_app` (לצד `pubspec.yaml`).
3. פתחו Terminal בשורש הפרויקט והפעילו:

```powershell
Expand-Archive -LiteralPath '.\masjid_card_actions_deletion_PATCH.zip' -DestinationPath . -Force
flutter analyze
flutter test
```

## חשוב! צריך לפרוס ארבע Cloud Functions חדשות
בלי הפעולה הבאה, כפתורי המחיקה החדשים יופיעו אך המחיקה ב־Firebase תיכשל.

```powershell
firebase deploy --only "functions:deleteCourse,functions:deleteActivity,functions:cleanupDeletedCourseRegistrations,functions:cleanupDeletedActivityAssets"
```

בדיקת פונקציות מקומית מדומה (אינה נוגעת ב־Firebase):

```powershell
node scripts/test-deletion-local.cjs
```

לאחר הפריסה:

```powershell
flutter run
```

בדקו בחשבון מנהל עם פריטי ניסיון, תחילה מחיקה עם ביטול בחלון האישור, ואחר כך מחיקה מאושרת. בדקו שהקורס/הפעילות נעלמים, שההרשמות הקשורות מוסרות, ושהתמונה נמחקת מ־Storage (ייתכן עיכוב בשל הטריגר). בדקו גם שבחשבון רגיל לא מוצגות פעולות מנהל.

### מה לא ניתן לאמת כאן
בסביבת הבדיקה הזו לא קיימים Flutter SDK או חיבור ל־Firebase שלכם. לכן נבדקו תחביר JavaScript, לוגיקה מדומה וקבצי המיזוג, אך נדרשת בדיקת `flutter analyze` והפעלת האפליקציה במחשב שלכם.
